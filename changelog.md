# Changelog

## 2.3.0 (2026-11-25)
- Fix beeps stopping after switching to another app and back ([#15](https://github.com/Pappum/tabata-timer/issues/15)).
- Optional cooldown phase at the end of the session ([#14](https://github.com/Pappum/tabata-timer/issues/14)).

## 2.2.0 (2026-11-18)
- Sound plays even when the iPhone is in silent mode ([#1](https://github.com/Pappum/tabata-timer/issues/1)).
- Home screen with a Tabata button leading to the settings ([#2](https://github.com/Pappum/tabata-timer/issues/2)).
- Settings: back button to the home screen, next to Démarrer.
- Preferences screen (gear on the home screen): light / dark / auto theme ([#3](https://github.com/Pappum/tabata-timer/issues/3)).
- Preferences: sound on / off for the beeps ([#4](https://github.com/Pappum/tabata-timer/issues/4)).
- End screen: Accueil button returns to the home screen.
- Code: clearer names; saved settings reset to defaults ([#7](https://github.com/Pappum/tabata-timer/issues/7)).

## 2.1.1 (2026-10-31)
- Docs: changelog, version badge and release steps in CLAUDE.md.

## 2.1.0 (2026-10-31)
- Fix timer screen height in iOS home-screen mode: controls and "Ensuite" now sit at the bottom of the screen.
- Prevent double-tap zoom.
- Settings: prep label and time on one row.
- App version badge at the bottom of the screen.

## 2.0.0 (2026-10-29)
- Redesigned UI.
- Durations in minutes and seconds, via −/+ or direct input.
- Cycles and rest between cycles; rounds renamed to sets.
- Settings screen shows the total session duration.
- Timer: phase colors, progress bar, set/cycle dots, total time left, next-phase pill, skip button, end screen.
- 5-second countdown beeps.
- Embedded fonts for offline use (Bebas Neue for digits, Figtree for text).

## 1.0.0 (2026-10-29)
- First version: prep, work, rest and rounds settings; timer with pause and stop; offline PWA.
